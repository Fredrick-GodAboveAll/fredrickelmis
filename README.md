# ELMIS — Modern HR Management System

This is the product marketing website for **ELMIS** (Employee & Leave Management Information System), a modern
HR platform being built from real HR experience. The site is a single, richly animated landing page presenting
the product, its leave management focus, the founder's story, and the wider HR platform roadmap.

## Tech stack

- [TanStack Start](https://tanstack.com/start) + TanStack Router (React 19)
- Vite 7
- Tailwind CSS 4
- Poppins (Google Fonts) and Material Symbols icons
- Deployed on Netlify

## Running locally

```bash
npm install
npm run dev
```

The dev server runs on port 3000 by default. If you want Netlify's local emulation (functions, redirects, etc.):

```bash
netlify dev
```
